# 2026-10-08 — #43 — A ZIO adapter for text, files and streamed checks

**Change:** ZIO applications can format text with typed refusals, format files atomically only when
the staged copy provably keeps its owner, group and every mode bit and write in place otherwise, and
stream a result for every checked file — an unchecked JDK failure stays that file's outcome —
without cats-effect; JVM / Native files and Scala.js text, in `ww86.hocon_fmt.interop.zio` so a
consumer's own `zio` import still resolves.

**Look at again before a release:** Recheck ZIO platform artifacts and the per-platform identity
sources (the JVM's unix view, the C library on Native) and the in-place fallback before releasing; a
replacement is a new file, so hard links keep the old content.
